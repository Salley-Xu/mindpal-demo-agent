## 五、问题根因分析

### 5.1 情绪模型 — Anger Recall 低 + Sadness Precision 低

- Anger 9 条只召回 3 条，5 条去了 sadness → 模型把"烦""被批评"类输入归为 sadness
- 可能原因：训练数据中 anger 类特征与 sadness 重叠，分类头决策边界不清晰
- 修复方向：增加 anger 类训练数据，特别是低强度 anger（annoyance 类）

### 5.2 风险模型 — Level 2/1 缺失

- **核心原因**: 训练数据中 Level 1/2 样本不足或标注不一致
- 模型退化成了 Level 0 vs Level 3 的二分类器
- **修复方向**:
  1. 检查训练集 `SOS-1K` 中 Level 1/2 的样本量
  2. 改为 ordinal regression loss（如 CORAL），强制模型学习有序关系
  3. 也可考虑合并 Level 1/2/3 → "需干预"，变为 2 分类再做细粒度

### 5.3 三级融合降分

- `binary_upgrade` 规则：binary_prob > 0.5 且 4class < 2 时升级到 Level 2
- 但 binary AUROC=0.437（低于随机），意味着 binary_prob 和真实标签**负相关**
- 建议：**立即禁用 binary_upgrade**，只用 4class + rule_override

### 5.4 Binary 分类头异常 (AUROC<0.5)

- 负 AUC 意味着二分类头学到了与真实标签相反的模式
- 可能原因：训练数据中正负样本比例极度失衡 + 未做 class weighting
- 或：模型没有收敛，二分类头的权重接近随机初始化

### 5.5 边界保护缺失

- `risk_evaluator._analyze_context()` 已检测到讨论语境和第三方归属，但结果未用于覆盖 BERT 输出
- 当前流程: BERT 预测 → context 分析 → **但 context 信息仅传给下游，不 override 级别**
- 修复方向: 在 BERT 预测后加硬规则：
  - 如果是 discussion_context → 降至 Level 0
  - 如果是 third_party + 无帮助请求 → 降至 Level 0
  - 如果是 safe_denial → 降一级
