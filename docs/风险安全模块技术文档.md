# 风险安全模块技术文档

## 概述

风险安全模块是 MindPal 的心理安全防线，负责对用户输入进行实时风险识别、会话级风险状态管理、以及跨会话长期风险记忆维护。模块采用**三级架构**：

```
当前用户输入
    ↓
┌─────────────────────┐
│  v4.2 BERT 单轮识别  │  文本级风险语义分类
│  MultiTaskBERT      │  (utterance-level)
└─────────┬───────────┘
          ↓
┌─────────────────────┐
│  v5.0 会话级聚合     │  多轮风险状态机
│  SessionRisk        │  (session-level)
│  Aggregator         │
└─────────┬───────────┘
          ↓
┌─────────────────────┐
│  v6.0 长期记忆       │  跨会话风险基线
│  RiskMemory         │  (user-level)
└─────────┬───────────┘
          ↓
   路由决策 →  Safety Gate 最终修正 → 输出
```

---

## 四级风险等级

定义在 `risk_levels.py`，所有模块统一使用：

| 等级 | 常量 | 含义 | 路由行为 |
|------|------|------|----------|
| Level 0 | `LEVEL_0` | 无/极低风险 | 正常 Agent 循环 |
| Level 1 | `LEVEL_1` | 持续负面情绪 | 加强安抚，轻量安全确认 |
| Level 2 | `LEVEL_2` | 中高风险，需结构化支持 | 专用高风险回复，推荐降级 |
| Level 3 | `LEVEL_3` | 紧急，立即干预 | 跳过 LLM，直接危机响应 |

核心工具函数：

```python
normalize_risk_level(level) → "level_0".."level_3"  # 别名归一化
risk_level_index(level)     → 0..3                   # 排序索引
risk_level_band(level)      → "low"|"medium"|"high"  # 兼容波段
is_emergency_risk(level)    → bool                   # 是否 Level 3
is_non_low_risk(level)      → bool                   # 是否 ≥ Level 1
```

## 第一层：BERT 单轮风险识别器

### 模块位置

- `backend/bert_risk_predictor.py` — 模型封装与推理
- `bert_data/models/v4_2_multitask_calibrated/best_model/` — 模型权重

### 模型架构

```
MultiTaskBERT (hfl/chinese-macbert-base)
  ├── classifier_4 → 4 分类 (level_0~level_3)
  └── classifier_2 → 二分类 (high_risk_binary)
```

### 三级融合推理

`BertRiskPredictor.predict(text)` 内部按优先级执行：

```
1. 规则兜底（20 条高危 regex pattern）
   命中 → 直接返回 level_3（绕过模型）
   例: "正在割腕", "这就去死", "遗书发出去了"

2. 二分类升级
   binary_prob > threshold(0.50) AND 4分类预测 < 2
   → 升级到 level_2

3. 4 分类预测
   默认走 softmax 取 argmax
```

### 调用方式

```python
from bert_risk_predictor import BertRiskPredictor

predictor = BertRiskPredictor(
    model_path="bert_data/models/v4_2_multitask_calibrated/best_model",
    device="cpu",            # 或 "cuda"
    binary_threshold=0.50,
)

result = predictor.predict("正在割腕")
# => {
#     "level": "level_3",
#     "level_4_prediction": 3,
#     "binary_probability": 1.0,
#     "class_probabilities": [0.0, 0.0, 0.0, 1.0],
#     "fusion_source": "rule_override",
#     "rule_matched": True,
# }
```

### 关键配置

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `BERT_MODEL_PATH` | `bert_data/models/v4_2_multitask_calibrated/best_model` | 模型路径 |
| `BERT_DEVICE` | `cpu` | 推理设备 |
| `BERT_BINARY_THRESHOLD` | `0.50` | 二分类融合阈值 |

## 第二层：会话级风险聚合器

### 模块位置

`backend/session_risk_aggregator.py` — `SessionRiskAggregator`

### 解决的问题

| 问题 | 示例 |
|------|------|
| 风险惯性 | 上轮 Level 3，本轮说"算了没事" → 不能直接降为 0 |
| 连续升级 | 连续 3 轮 Level 1，每轮都不严重但累积了 |
| 趋势识别 | 快速判断风险在上升还是下降 |
| 安全确认 | 用户明确否认后可以参与降级 |

### 聚合规则（按优先级）

```
输入: utterance_level (BERT 单轮等级)
      baseline (长期风险基线)

规则 1: 当前轮 Level 3 → 会话等级 = 3（立即返回）
规则 2: 当前轮 Level 2 → 会话等级 ≥ 2（下限）
规则 3: 风险惯性
  - 上轮 ≥ 3 且当前 < 2 → 至少 Level 2
  - 上轮 ≥ 2 且当前 = 0 → 至少 Level 1
规则 4: 连续升级
  - 5 轮窗口内 Level 2 出现 ≥ 2 次 → 至少 Level 2
  - 5 轮窗口内 Level 1 出现 ≥ 3 次 → 至少 Level 1
规则 5: 安全确认降级
  - 当前轮否认 + 窗口无 Level 2+ + 有求助意图 → 降一级
规则 6: Safety Gate（长期基线修正）
  - baseline=high 且等级 < 1 → 提到 Level 1
  - baseline=medium 且非全部 Level 0 → 提到 Level 1
规则 7: 趋势判定
  - 窗口后半段平均 > 前半段 0.3 → rising
  - 窗口后半段平均 < 前半段 0.3 → falling
  - 否则 → stable
```

### 输出结构

```python
{
    "session_level": "level_2",          # 聚合后的等级
    "risk_trend": "rising",              # rising / stable / falling
    "session_aggregation": {
        "utterance_level": "level_1",
        "utterance_binary_prob": 0.35,
        "utterance_rule_hit": False,
        "window": ["level_0", "level_1", "level_2", "level_1", "level_1"],
        "safety_confirmed": False,
        "active_rules": [
            "inertia:prev_level_3_floor_2",
            "baseline:high_floor_1",
        ],
    },
}
```

### 滑动窗口

默认 5 轮，从 `conversation_summary["recent_risk_levels"]` 读取。

## 第三层：长期风险记忆层

### 模块位置

`backend/risk_memory.py` — `RiskMemoryWriter` + `RiskMemoryReader`

### 设计原则

| 原则 | 说明 |
|------|------|
| 不诊断 | 记录"用户近期 3 次出现 Level 2+"，不记录"用户有自杀倾向" |
| 近期化 | 7~14 天时间窗口，不永久贴标签 |
| 最小化 | 只存安全必需的信息 |
| 可衰减 | 30 天无事件自动 decay |

### 数据存储

所有数据存储在现有 `user_profile.preferences` JSON 字段的 `risk_memory` 键下，不新增数据库表。

```json
{
  "risk_memory": {
    "baseline": "high",
    "baseline_updated_at": "2026-07-05T10:30:00",
    "risk_events": [
      {
        "event_time": "2026-07-05T10:30:00",
        "session_id": "sess_001",
        "max_level": "level_3",
        "topic": "学业",
        "summary": "因考试压力产生焦虑情绪，表达明显痛苦",
        "safety_confirmed": false,
        "support_engaged": false,
        "decayed": false
      }
    ],
    "common_triggers": ["学业", "求职"],
    "protective_factors": ["愿意联系朋友"],
    "last_high_risk_time": "2026-07-05T10:30:00",
    "last_safety_confirmation": null,
    "decay_status": "active"
  }
}
```

### 写入条件

| 条件 | 操作 |
|------|------|
| 当前轮等级 ≥ Level 2 | 写入 `risk_event` |
| 同一 topic 在 `common_triggers` 中出现 ≥ 2 次 | 更新 `common_triggers` |
| 用户安全否认 + 窗口无 Level 2+ | 更新 `last_safety_confirmation` |
| 普通低风险（Level 0-1） | 不写入 |
| 第三方/讨论语境 | 不写入 |

### 基线计算规则

```
7 天内出现 Level 3                     → baseline = high
7 天内出现 2 次以上 Level 2             → baseline = high
14 天内出现 Level 2                    → baseline = medium
14 天内出现 3 次以上 Level 1            → baseline = medium
14 天无事件                             → baseline = low
超过 30 天的事件标记 decayed，不参与计算
```

### 调用方式

```python
from risk_memory import RiskMemoryReader, RiskMemoryWriter

# 读取（每轮开始）
memory = await RiskMemoryReader().get_baseline(user_id)
# => {"baseline": "medium", "common_triggers": [...], ...}

# 写入（每轮结束）
await RiskMemoryWriter().update(
    user_id=user_id,
    session_id=session_id,
    risk_state=urgent_issue,
    conversation_summary=summary,
    emotion_state=emotion_state,
)
```

## 数据流全景

```
用户输入 "我想死"
    │
    ▼
agent_orchestrator.run_agent()
    │
    ├── 1. 加载长期基线
    │   RiskMemoryReader.get_baseline(user_id) → baseline="high"
    │
    ├── 2. 情绪分析
    │   emotion_analyzer.analyze_with_context_async() → "绝望"
    │
    ├── 3. BERT 单轮预测
    │   BertRiskPredictor.predict("我想死") → utterance_level="level_3"
    │
    ├── 4. 会话级聚合
    │   SessionRiskAggregator.aggregate(
    │       utterance_level="level_3",
    │       baseline="high",
    │   ) → session_level="level_3"
    │
    ├── 5. 推荐门控
    │   recommend_gate.decide(risk_state) → recommend_type="none"
    │
    ├── 6. 路由决策
    │   is_emergency_risk("level_3") → True
    │   → urgent_detector.generate_crisis_response_async()
    │
    ├── 7. 输出安全检查
    │   output_safety_checker.review(response) → 模式匹配过滤
    │
    └── 8. 持久化
        ├── conversation_manager.add_interaction() → 存本轮记录
        └── RiskMemoryWriter.update() → 更新长期记忆
```

## 上下文分析（路由用）

`risk_evaluator._analyze_context(text)` 使用纯 regex 识别文本语境，不依赖模型：

```python
context = {
    "subject": "self" | "third_party" | "discussion",
    "is_third_party_risk": bool,
    "is_help_request": bool,
    "is_discussion_context": bool,
    "is_safe_denial": bool,
}
```

影响路由：第三方 + 求助 → 走 `ThirdPartyCrisisSupport` 分支，不提升用户自身风险基线。

## 输出安全检查

`backend/output_safety_checker.py` 在最终回复出站前做规则化过滤：

| 规则 | 示例命中 |
|------|---------|
| 无效化语言 | "你想太多了"、"别矫情" |
| 过度保证 | "一定不会有事" |
| 鼓励孤立 | "一个人待着"、"自己消化" |
| 危险细节 | "怎么自杀"、"药量" |
| 高风险下普通推荐 | Level 2+ 时推荐冥想/运动文章 |

命中任意规则 → 替换为安全兜底回复。

## 扩展指南

### 修改规则兜底 pattern

编辑 `bert_risk_predictor.py` 中的 `HIGH_RISK_OVERRIDE_PATTERNS` 列表。每条 pattern 命中直接输出 Level 3。

### 调整会话聚合参数

修改 `session_risk_aggregator.py` 中的 `WINDOW_SIZE`（默认 5）或趋势阈值（`diff > 0.3`）。

### 调整基线衰减窗口

编辑 `risk_memory.py` 中的时间常量：

```python
_HIGH_RISK_WINDOW = timedelta(days=7)      # 7 天内 Level 3 → high
_MEDIUM_RISK_WINDOW = timedelta(days=14)   # 14 天内 Level 2 → medium
_EVENT_DECAY = timedelta(days=30)          # 30 天后标记 decayed
```

### 添加新的风险主题

在 `risk_memory.py` 的 `_TOPIC_KEYWORDS` 字典中添加：

```python
_TOPIC_KEYWORDS = {
    "健康": ["生病", "医院", "手术", "体检"],
    # ...
}
```
